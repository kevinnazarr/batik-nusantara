# 21. Sitemap & Navigation

## Customer

- `/` Home
- `/shop` Product catalog
- `/category/{slug}` Category listing
- `/product/{slug}` Product detail
- `/search?q=` Search results
- `/cart` Cart
- `/checkout` Checkout
- `/order/{orderNumber}` Guest/registered order access
- `/order/success` Order success
- `/login` Login
- `/register` Register
- `/forgot-password` Password reset
- `/account` Account overview
- `/account/orders` Orders
- `/account/orders/{orderNumber}` Order detail
- `/account/addresses` Addresses
- `/account/wishlist` Wishlist
- `/stories` Batik stories
- `/stories/{slug}` Story detail

## Admin

- `/admin` Dashboard
- `/admin/orders`
- `/admin/orders/{id}`
- `/admin/products`
- `/admin/products/create`
- `/admin/products/{id}/edit`
- `/admin/categories`
- `/admin/inventory`
- `/admin/customers`
- `/admin/promotions`
- `/admin/banners`
- `/admin/stories`
- `/admin/settings`

## Navigation rules

Desktop customer navigation: logo, Shop, categories, Stories, search, account, cart. Mobile navigation: logo, search, cart, menu drawer. Admin navigation is task-oriented: Dashboard, Orders, Catalog, Customers, Marketing, Content, Settings.
