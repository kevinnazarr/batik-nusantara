# 43. Content Model & Editorial Rules

## Product copy

Product title should identify item + motif/type where useful. Short description communicates material, technique, and fit/use case. Long description explains care, origin/context, and meaningful differentiators.

## Story copy

Stories should prioritize cultural/contextual accuracy, clear sourcing when historical claims are made, and avoid inventing provenance. Content must distinguish known facts from brand storytelling.

## Image rules

Product images: consistent aspect ratio, clean primary shot, detail shots, context/model shot when helpful. Alt text describes the content and purpose rather than decorative marketing language.
