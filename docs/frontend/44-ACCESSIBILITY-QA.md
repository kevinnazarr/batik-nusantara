# 44. Accessibility QA Checklist

- [ ] Full keyboard journey from home to checkout.
- [ ] Focus visible in all dialogs/drawers.
- [ ] Screen-reader labels for icon-only controls.
- [ ] Error messages announced and associated with fields.
- [ ] Variant selection usable without color alone.
- [ ] Reduced motion respected.
- [ ] Images have useful alt text.
- [ ] Contrast checked for text, controls, and disabled states.
- [ ] Touch targets have adequate size/spacing.
- [ ] Checkout works without animation dependencies.
