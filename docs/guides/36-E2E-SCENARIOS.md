# 36. End-to-End Scenarios

## Customer

1. Guest buys single-variant product.
2. Guest buys multi-variant product.
3. Registered user buys using saved address.
4. Customer applies valid coupon.
5. Customer sees out-of-stock variant.
6. Payment succeeds and order becomes paid.
7. Payment expires and reservation releases.
8. Shipment is created and tracking is visible.
9. Guest accesses order using secure token.
10. Customer cancels an eligible order.

## Admin

1. Create category.
2. Create product with options and variants.
3. Upload gallery and set primary image.
4. Restock SKU and see inventory movement.
5. Process paid order to packed/shipped.
6. Apply promotion and verify order discount.
7. Publish story and attach products.
8. Inspect webhook/audit history.
