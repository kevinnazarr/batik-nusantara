# 38. Sprint Plan

Assumption: solo developer, part-time/full-time flexible. Sprint length is a planning unit, not a promise.

## Sprint 0 — Foundation

Repo, Docker, environments, Laravel, Next.js, PostgreSQL, Redis, CI baseline.

## Sprint 1 — Catalog

Categories, products, options, variants, images, public catalog API/UI.

## Sprint 2 — Auth + Account

Email auth, Google OAuth, account, addresses, guest session model.

## Sprint 3 — Cart + Checkout

Cart, pricing validation, shipping quote integration, order creation.

## Sprint 4 — Payment

Midtrans flow, webhook, payment state machine, confirmation emails.

## Sprint 5 — Fulfillment

Biteship, shipment creation, tracking, admin order workflow, inventory movement.

## Sprint 6 — Admin + Content

Dashboard, products, inventory, promotions, banners, stories.

## Sprint 7 — Hardening

Security, E2E, performance, SEO, analytics, accessibility, backup/recovery.

## Sprint 8 — Launch

Production setup, smoke test, monitoring, documentation, portfolio case study.
