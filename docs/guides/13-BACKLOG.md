## Definition of Done

Sebuah task selesai ketika:

- code merged;
- tests sesuai risiko tersedia;
- UI responsive jika ada UI;
- loading/error/empty state ada;
- authorization diperiksa;
- observability/logging cukup;
- dokumentasi contract diperbarui jika perlu.
