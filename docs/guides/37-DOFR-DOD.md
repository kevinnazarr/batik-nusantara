# 37. Definition of Ready / Done

## Definition of Ready

A task is ready when acceptance criteria exist, dependencies are known, API/UI contract is clear enough, and edge cases that affect implementation are identified.

## Definition of Done

- Acceptance criteria pass.
- Tests added/updated.
- Lint/typecheck pass.
- Responsive behavior verified.
- Accessibility basics verified.
- Error/loading/empty states handled.
- Logs do not leak secrets/PII.
- Documentation updated when architecture/API changes.
- PR reviewed and CI green.
